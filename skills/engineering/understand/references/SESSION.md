# Session edges

The loop and the pause rule stay in `SKILL.md`. This file is the two menus.

## Interest Discovery

Use when Focus & Goals has no subject yet.

AskUserQuestion for the goal, the familiarity, and the learning style. The goal options match the subject: for code, contribute / fix / review / explore; for any subject, explain it / use it / answer one question. Familiarity: never / a bit / comfortable / very. Learning style matches the subject: for code, tracing a path / reading tests / a worked example; otherwise, tracing a path / a worked example / the source of the claim. Ask in the open what pulled them here.

Record under `## Focus & Goals`: primary goal, interests, background, learning style.

Done when those four lines are filled and the subject is named.

## Session end

The learner is ending the session. A release back to parked work is this case: state what now makes sense, write the journal, and stop. The menu is for when the next step is unclear.

1. State what now makes sense, in the concrete terms of this subject.
2. Write the journal quietly. Include `Current thread` so the next session can resume. Mention the write when that line is what they need in order to come back.
3. AskUserQuestion only when the next step is unclear: continue this subject / quiz this session / pause / switch subject.

Done when the turn states what now makes sense and the journal has `Current thread`.
