# Anti-AI tells

Final scrub after density and medium rules. Em dash and en dash ban, and filler-adverb cuts: [SKILL.md](SKILL.md) §6 and §4.

- Rewrite on one sighting: chatbot residue, sycophancy, knowledge-limit disclaimers, not-X-but-Y, arguing with no one, signposting.
- Every other row needs a cluster. One ordinary word ("robust", "ensuring", "leverage") stays.
- Missing a real detail: ask or keep plain. Never invent facts, names, dates, or citations, and never swap a vague claim for an invented specific.

## §1 Cut or rewrite

| Tell | Action |
| --- | --- |
| Significance inflation ("pivotal moment", "testament to", "evolving landscape") | State the concrete fact |
| Superficial `-ing` tack-ons ("highlighting…", "showcasing…", "ensuring…") | Delete, or keep only sourced substance |
| Promotional fluff ("vibrant", "seamless", "robust", "nestled", "groundbreaking") | Plain wording. Keep a technical "robust" |
| Vague attributions ("experts believe", "observers note") | Name a real source or cut |
| Knowledge-limit disclaimers ("as of my last update", "based on available information", "it is believed that") | Cut the disclaimer; keep the known fact |
| AI vocabulary pile-up (delve, tapestry, underscore, leverage, facilitate, utilize) | Ordinary verbs |
| Copula avoidance ("serves as", "boasts", "features") | Prefer "is" / "has" |
| "Not just X, but Y" / tailing negations ("…, no guessing"); the same contrast split across two sentences | State the point once |
| Arguing with no one ("This isn't about…", "To be clear", "Don't get me wrong") | State the point |
| Rule-of-three padding | Use a natural number of items |
| Repeated sentence openings | Vary later openings when the repetition is a pattern |
| Synonym cycling for the same referent | Repeat the clearest noun |
| False ranges ("from X to Y" spanning unrelated topics) | List directly |
| Bold / emoji / Title Case decoration | Plain prose for the medium |
| Inline-header lists ("**Performance:** it improved") | Prose or real lists per mode |
| Chatbot residue ("I hope this helps!", "Happy to help further", "Of course!", "Would you like me to…", "Should I continue?") | Remove |
| Sycophancy ("Great question!", "You're absolutely right!") | Answer directly |
| Signposting ("Let's dive in", "Here's the thing", "Let's be honest") | Start with the content |
| A heading repeated by the next sentence | Start the section with the new fact |
| Writing about the document ("This section is organized by…", "the table below compares…") | State the subject |
| Persuasive authority tropes ("At its core", "What really matters") | Ordinary claim |
| Closers that restate or cheer ("That is the real win.", "Exciting times ahead"); a one-line paragraph that only repeats the previous one | End on the last concrete fact or ask |
| Manufactured staccato drama (stacked one-liners) | Varied, concrete sentences |
| Aphorism formulas ("X is the Y of Z") | Concrete claim |
| Theatrical fake-candid openers ("Honestly?" as a standalone hook) | Just say the thing |

## §2 Preserve (not tells alone)

- Specific hard-to-fake detail.
- Mixed feelings or unresolved tension.
- Varied sentence length.
- Genuine mid-sentence "honestly" or "look" when it carries the point.
- One short emphatic sentence, not a run.
