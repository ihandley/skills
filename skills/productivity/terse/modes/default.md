# Default

Use this mode when the destination medium is unspecified or unsupported.

- Use complete sentences.
- Do not add a greeting, sign-off, ticket sections, or chat slang unless the source already has them.

When [../links.md](../links.md) says to link, write `name (url)`. Otherwise keep the raw URL or the exact identifier. Do not use Slack, Jira, Confluence, or GitHub link syntax.
