# Scope

This repo is the set of skills I use. It is curated. Issues track changes to the skills.

## The bar

A change stays when both are true:

1. **Observed failure.** It describes something that went wrong in a real session: what ran, what the skill did, what was expected.
2. **Fits this repo.** It is a skill I will actually run, small enough to compose with the others, and it belongs in one bucket under `skills/`.

## By bucket

- **`engineering/`, `productivity/`**: promoted. Listed in the top-level README, shipped in the Claude Code plugin, and documented under `docs/`.
- **`in-progress/`**: public on purpose, excluded from the plugin until it graduates.
- **`misc/`**: kept, rarely used, not promoted.
- **`deprecated/`**: removed from use. Delete the skill. The changeset names whatever replaced it.

## Already decided

Each file in [`.out-of-scope/`](./.out-of-scope/) records one rejected concept and why. Read them before adding a skill that might already have been turned down.
